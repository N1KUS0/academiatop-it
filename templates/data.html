Выключение ПК

Кнопки «Выключить» на страницах ПК и аудиторий и в блоке «ПК в сети» выключают компьютеры по сети от имени доменной учётной записи с правами администратора на ПК. Пользователь видит предупреждение, через минуту ПК выключается.

{% if shutdown_account %}

Включено. Учётная запись: {{ shutdown_account.domain ~ '\\' if shutdown_account.domain }}{{ shutdown_account.username }}

{% else %}

Сейчас выключено: учётная запись не задана.

{% endif %}

Учётная запись хранится на сервере в отдельном файле (не в базе и не в копиях в Telegram), поэтому задаётся только на сервере:

cd /opt/registry && sudo -u registry REGISTRY_DB=/opt/registry/instance/registry.db .venv/bin/flask --app app set-shutdown-account
